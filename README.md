# Book Scanner → PDF

Mobile web page-scanner for physical books.

1. Open the GitHub Pages URL on your phone (HTTPS required for camera).
2. Allow **back camera**.
3. Tap the shutter once per page.
4. Tap **End → PDF** to download one multi-page PDF.

Optional: **Or import photos instead** if you already shot pages in the camera app.

Privacy: pages stay in the browser until you download the PDF. Nothing uploads to a server.
